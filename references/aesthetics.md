# 美感：從八十個得獎作品歸納的原則

這份不是技巧清單，是看完約八十個 Awwwards 得獎作品（年度最佳、每月最佳、近兩個月的當日最佳，橫跨飲品、時尚、建案、金融、AI、音樂、藝術、遊戲、作品集）之後，歸納出「為什麼這些畫面好看」。動手前讀，做完拿來檢查自己。

一句話：**好看的網站，每一個決定都來自同一個主題世界，而且每個決定都做到極端，不做到一半。**

---

## 一、先建立「主題世界」，再做畫面

每個得獎網站都像走進一個完整的世界，字體、顏色、影像、動態、連細節都出自同一個地方：

- **Lando Norris**（F1 車手）：深橄欖綠底上浮著安全帽的等高線，螢光萊姆綠只用在幾個斜體字上，大寫窄體字像賽車號碼。
- **Son Daven**（山中度假飯店）：卡其與羊毛色，字標用像羊毛織出來的點陣字，載入畫面是一隻羊。
- **ERA Residence**（地中海住宅）：拱形窗框住泳池與棕櫚，草寫字加細明體，連 cookie 提示都是一張草寫字卡片。
- **Oryzo**（軟木杯墊）：產品放在綠色切割墊上，格線與尺寸標記就是版面的格線。
- **Aardvark**（讀書俱樂部）：飽和的黃橙波浪、書封當主角、手寫註記，像拆開一箱書。
- **White Desert**（南極旅行）：冰原照片、寬大的白色窄體字被霧蓋住。

做法：動手前寫一張**主題世界表**，每一格都要從主題本身找答案，不能填「現代」「簡約」這種形容詞：

| 項目 | 要回答的問題 | 例：高山茶品牌 |
|---|---|---|
| 材質 | 這個世界摸起來是什麼？ | 炭焙的茶色、粗紙、霧氣、瓷 |
| 顏色 | 這個世界真實存在的顏色 | 焙火的深褐、茶湯的琥珀、山霧的灰白 |
| 字的性格 | 這個世界會用什麼字？ | 手寫楷書的節奏、直排 |
| 影像 | 用什麼畫面講它？ | 茶葉、蒸氣、等高線、海拔 |
| 動詞 | 這個世界裡的東西怎麼動？ | 舒展、沖開、飄散、沉澱 |
| 細節 | 只有這個世界才有的小東西 | 海拔數字、焙火時數、採摘節氣 |

動態就從「動詞」那一格來，這是讓每個主題的動畫都不一樣的關鍵（見 `motion.md`）。

## 二、字：有個性，大小差到極端

- **極端的大小對比**：主標 8 到 20vw，旁邊的資訊字 11 到 13px，中間尺寸很少。大字就要大到佔滿版面、甚至被裁切。
- **選有個性的字**：窄體大寫（Lando、Akaru、Decathlon）、寬體（Son Daven）、高反差明體配斜體或草寫（ERA、Sobha、LxL）、極細大字（Montfort、Riotters）。字本身就是主題的一部分。
- **同一句話混用**：在大寫窄體裡插幾個明體斜體字（Lando）、在大寫段落裡插草寫字（LxL）、把小圖片直接放進句子當一個字（Watson、Noho、Kalkbrenner）。
- **行高很緊**：大字行高 0.85 到 0.95，字距收緊；小字反而行高寬鬆、字距稍開。
- 中文：字體要跟情況相符，見 `typography.md`。精品用細明體（思源宋體 200、300）；文學與傳統用仙人掌明體；熱鬧的用極粗黑體；親切的用圓體；楷書只給手作與教育，用在精品會掉價。直排是中文獨有的武器。

## 三、顏色：少，而且大膽

- 常見組合是**一大片主色**（整頁番茄紅、整頁深藍、整頁粉紅、整頁草綠）加上墨色，再加一個強調色。面積大，才有主張。
- 或者近乎無彩（白、灰、霧），只靠一個小小的強調色。
- 照片統一調色：雙色調（Kalkbrenner 的綠、Illoca 的藍）、同一個色溫，整頁看起來才像同一個世界。
- 顏色要從主題世界表的「顏色」那格來，不從配色網站挑。

## 四、影像：經過藝術指導

- 滿版、出血、特寫，有電影感的光線；不是在白框裡放一張小圖。
- 產品用有真實材質的渲染（Oryzo 的軟木、Moto 的金屬卡、Sharplink 的鍍鉻）。
- 插畫要有獨特的畫風，而且整站一致（Illoca 的藍色雙色調、Decathlon 的七〇年代、Aardvark 的手繪感）。
- 沒有真實素材時：用 SVG 為這個主題畫有風格的插圖，或用程式畫出跟主題有關的視覺（水墨、蒸氣、等高線、生成藝術），或讓字本身當影像。

## 五、版面：格線要嘛很嚴，要嘛刻意打破

- **很嚴**：看得見的格子、細線、索引數字（Aspen 的格子與網點、Pangram 的字體卡、Dropbox 的色塊磚、Inkfish 的等寬清單）。
- **刻意打破**：拼貼、散落、繞圈排列的作品（Gionatan、Bleibtgleich）、斜放的貼紙。
- 兩者都可以，最差的是兩邊都不是的「一般網頁排版」。

## 六、節奏：每一段的密度都不一樣

得獎網站往下捲，會在「滿版影像、一句大字、密集格線、大量留白、一段長文」之間交替，像音樂有強弱。整頁同一種密度、同一種卡片，就會無聊。

## 七、留白是奢侈品

精品與高價服務（Montfort、Watson、Sobha）用大量留白、很少的元素、很細的字。留白要多到讓人覺得「可以放東西卻沒放」。

## 八、細節都設計過

量出來的細節數字與放大檢查在 `details.md`。高級、安靜的主題尤其要看第五節：沒有好影像時，不要用簡筆圖示充數。

- 括號標籤（（Recently））、上標數字（LATEST¹¹）、索引編號、時區時鐘、載入計數（05/24 fps、87%）。
- 自訂游標、聲音開關、按鈕的質感。
- 連 cookie 提示、載入畫面、404 都照主題設計。

## 九、檢查自己：並排比對

做完後，把自己的首屏與往下兩屏的截圖，跟同類型的 3 個得獎作品截圖並排，逐項問：

1. 字有沒有一樣的個性與大小反差？
2. 顏色有沒有一樣的主張，還是猶豫的中間色？
3. 影像或視覺是不是為這個主題做的？
4. 節奏有沒有強弱變化？
5. 動態是不是這個主題的「動詞」，還是隨便套的效果？
6. 細節有沒有設計過？

任何一項明顯輸，就回頭改，不要交出去。
